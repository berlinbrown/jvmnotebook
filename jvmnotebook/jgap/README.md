# JGAP (Genetic Algorithms library)

This repository includes a bundled copy of JGAP examples and supporting jars under `jgap/lib/jgap/`.

Notes:
- See `jgap/lib/jgap/readme.txt` for build notes and instructions. An Ant build script is included for the example code.
- Some examples require third-party jars (Colt, etc.) which may not be bundled due to licensing; check the readme and `lib/` directory.
