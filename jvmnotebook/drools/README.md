# Drools demo

Contains Drools rule files and example Java code.

Structure:
- `src/` — example `.drl` files and Java classes (examples: `HelloWorld.drl`, `Fibonacci.drl`).
- `lib/` — third-party jars used by the demos.
- `log/` — sample run logs.
- `build.xml` — Ant build file (use `ant` in this directory to build examples if Ant is available).

Notes:
- Runs are typically small demo programs that demonstrate rule execution and logging. Inspect `src/` and `log/` for examples and expected output.
