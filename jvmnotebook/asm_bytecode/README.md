# ASM (bytecode) examples

This directory contains small example sets that demonstrate how to generate and manipulate JVM bytecode using ASM.

- `simple_examples/` — grouped example sets (`set1`, `set2`, `set3`, `set4`), each with Java sources showing bytecode generation and manipulation.

How to run:
- Inspect the example's `src/` and run with `javac`/`java` as appropriate. Some examples are self-contained and print output illustrating bytecode-emitted classes.

Notes:
- These examples are educational and demonstrate low-level bytecode techniques rather than production patterns.
