# Jython examples

Jython allows Python code to run on the JVM and seamlessly import Java classes. This folder contains a few demos and unit test examples.

Notable items:
- `UnitTestPy/` — examples that combine JUnit and Jython-based tests. See the `README` inside for test run instructions.
- `JythonBotStrutsExample/` — an example web app demonstrating Jython + Struts components.

Note: Jython versions here are historic; running certain examples may require adjustments to work with modern Jython releases.
