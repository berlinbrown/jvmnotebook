# Scala examples

This folder contains a few Scala-based demos:

- `geneticadder/` — example Scala project (possibly related to genetic algorithms in the repo).
- `jgap/` — Scala-related integration/examples with JGAP.
- `scala_stock/` — stock demo/examples written in Scala.

Notes:
- Scala code may target older Scala versions; check source and test before upgrading language/runtime.
