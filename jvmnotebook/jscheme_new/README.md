# Jscheme (Scheme in Java)

Jscheme is a minimal Scheme implementation in Java (originally by Norvig). This directory contains the `docs/`, `lib/`, `src/`, and `tests/` for the project.

Reference:
- http://norvig.com/jscheme.html

Notes:
- The project is educational, showing a compact interpreter implementation. Use the tests to see example usage and expected behavior.
